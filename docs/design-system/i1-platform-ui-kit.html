04

Re-skinning for a new app or client

The four-line theme
A new client ships as a token override file loaded after the base tokens. Nothing else changes.
:root {
  --brand:        #0067a0;
  --brand-hover:  #005585;
  --brand-active: #00456b;
  --font-sans:    "Your UI Font", ui-sans-serif, system-ui;
}
Rules that keep it portable
01No component hard-codes a colour, radius or family — every value resolves to a token.
02Brand colour appears in exactly four places: sidebar, primary action, focus ring, selected state.
03Status colours are semantic and never re-skinned — green means done in every client.
04Logos are slots, not images in components: mark for the rail, lockup for login.
05Copy is sentence case, factual, no exclamation marks and no emoji.
06One icon set across all apps, stroke style, 16 / 18 / 20 / 26px only.
